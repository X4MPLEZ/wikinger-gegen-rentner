# AGENTS.md

The full guide for coding agents is **[CLAUDE.md](CLAUDE.md)** (file map, how the game runs, recipes, testing). The essentials:

- Edit `src/` only. `index.html` is generated by `node tools/build.mjs`.
- All `src/js/*.js` files share one scope (concatenated in name order, no imports): grep before adding a top-level name.
- The simulation runs only on the host; guests draw snapshots (`snapOf` in src/js/14-sim-step.js). Changed snapshot, command or
  presence shapes → bump `NET_VER` in src/js/61-net.js.
- Player-facing text is German, code and comments English. Prettier style (printWidth 140, single quotes).
- Test with `sh tests/run.sh` (online changes: `sh tests/run.sh mp`).
